# Cine AI Stylist 🎬👗

AI-powered movie costume designer.
Built for Kaggle + Google ADK Hackathon.
## What it does
- Creates movie character looks
- Suggests costumes by era
- Helps directors & designers

## How to run
pip install -r requirements.txt
python main.py
